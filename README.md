# YulyfCentre — prototype

Prototype fonctionnel et responsive de YulyfCentre pour les centres multidisciplinaires.

Cette première couche utilise uniquement des données fictives et les comptes explicitement dédiés aux tests (`Praticien technique C` et `Patient technique C`). Elle ne contient aucune donnée médicale réelle et ne se connecte pas encore à Appwrite.

Le contenu publié se trouve dans `dist/`.
